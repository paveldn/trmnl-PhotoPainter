QUICK START

Flash, configure, then let it sleep.

  1. 01

    Connect

    Use a data-capable USB-C cable, power on the PhotoPainter, and close any serial monitor using the port.

  2. 02

    Install

    Select Connect & install, choose the ESP32-S3 serial port, and follow the prompts.

  3. 03

    Configure

    Join the PhotoPainter-TRMNL Wi-Fi network and enter Wi-Fi and TRMNL server details.
